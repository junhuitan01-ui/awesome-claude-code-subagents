# Project brief

> **Test project.** Acme Widgets Ltd and all data in this folder are fictional. They exist only to demonstrate the pipeline end to end without needing web access.

## Project name
example-acme-pilot

## Purpose
Help Acme's directors decide whether to make the six-month four-day week pilot permanent, extend it, or end it.

## Audience
Acme's board of directors (non-specialists). They want a short, balanced summary and a clear recommendation.

## Research questions
1. How did output, customer service and absence change during the pilot compared with the six months before it?
2. How did staff wellbeing change, and did it differ between teams?
3. What problems came up during the pilot, and what caused them?

## Scope
- **In scope:** The pilot (January–June 2026) and the six months before it (July–December 2025), using only the files provided.
- **Out of scope:** External research on other companies' trials; legal or contract advice.
- **Time period / geography:** July 2025 – June 2026; Acme's single UK site.

## Sources
- **Preferred or required sources:** Only the files provided in this folder. Do not use web research for this project.
- **Sources to avoid:** Anything not in this folder.
- **Files provided:** `pilot-metrics.csv` (monthly operations data), `staff-survey-summary.md` (before/after survey), `manager-notes.md` (issues log)

## Success criteria
- [ ] Answers all three research questions using the provided data, with citations
- [ ] Reports the limitations of the data (e.g. short period, survey response rates)
- [ ] Gives a clear recommendation with conditions
- [ ] Every number has a citation and matches the source files

## Constraints
- **Deadline:** none
- **Length / effort limits:** short (test run)
- **Other:** none
