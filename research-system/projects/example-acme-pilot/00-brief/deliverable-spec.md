# Deliverable specification

## Files to deliver
- `report.docx` — board report
- `report.pdf` — PDF copy of the report
- `slides.pptx` — board presentation
- `data.xlsx` — supporting data

## Report requirements
- **Length:** 700–1,100 words
- **Required sections (in order):** Executive summary; Background; Findings; Limitations; Recommendation; References
- **Must include:** a before/after comparison table

## Slide requirements
- **Number of slides:** 5–7
- **Must include:** title slide, key findings, limitations, recommendation, sources slide
- **Speaker notes:** yes

## Spreadsheet requirements
- **Sheets and columns:** "Monthly metrics": Month, Period, Units shipped, On-time delivery (%), Customer complaints, Sick days, Source; "Survey": Measure, Before, After, Change, Source

## Style
- **Style guide:** `style-guide.md`
- **Citation style:** numbered [1] with reference list
- **Branding:** none
