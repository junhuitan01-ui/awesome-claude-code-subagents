# Deliverable specification

## Files to deliver
- `report.docx` — main written report
- `report.pdf` — PDF copy of the report
- `slides.pptx` — summary presentation for the directors
- `data.xlsx` — table of the trials reviewed

## Report requirements
- **Length:** 800–1,200 words
- **Required sections (in order):** Executive summary; Background; Findings; Limitations of the evidence; Recommendation; References
- **Must include:** a table comparing the trials reviewed

## Slide requirements
- **Number of slides:** 5–7
- **Must include:** title slide, key findings, limitations, recommendation, sources slide
- **Speaker notes:** yes

## Spreadsheet requirements
- **Sheets and columns:** "Trials": Trial, Country, Year, Organisations, Key result, Source

## Style
- **Style guide:** `style-guide.md`
- **Citation style:** numbered [1] with reference list
- **Branding:** none
