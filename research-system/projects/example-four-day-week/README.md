# Example: research blocked (honest stop)

This run was made on a test machine whose network blocked web pages. Web search worked, but every attempt to open a source failed.

The researcher refused to cite anything it couldn't read. It recorded the leads it found as "not verified", and the orchestrator stopped after step 1 instead of writing a report from no evidence. See `01-research/research-notes.md` and `pipeline-log.md`.

On a normal computer with web access, running `/deliver example-four-day-week` would continue through all the steps.
